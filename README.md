# AI Email Assistant

This project started as an attempt to make email information easier to search and interact with using natural language.

The application fetches emails, processes the content, and allows users to query email information through an AI-powered interface instead of manually searching through messages.

While building this project, I explored concepts such as NLP, information retrieval, and Retrieval-Augmented Generation (RAG) to improve the relevance of responses generated from email data.

## What I Built

- Email fetching and processing pipeline
- Email content preprocessing and text handling
- Retrieval-based context generation
- AI-powered question answering over email data
- Streamlit interface for user interaction

## Tech Stack

- Python
- Streamlit
- NLP libraries
- Retrieval-Augmented Generation (RAG)

## Learning Outcomes

Through this project I gained hands-on experience with:

- Working with unstructured text data
- Building retrieval pipelines
- Integrating AI models into applications
- Designing end-to-end Python applications
- Creating user-facing AI tools

## Current Limitations

This is still an ongoing project and there are several areas I would like to improve:

## Running the Project

Install dependencies:

pip install -r requirements.txt

Start the application:

streamlit run app.py
